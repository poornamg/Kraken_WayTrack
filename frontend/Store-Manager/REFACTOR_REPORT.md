# Store Manager Refactor Report

## Summary
Successfully refactored the monolithic `App.tsx` (4648 lines) into small, clear, reusable modules while strictly preserving all UI rendering, logic, and behavior. The root `App.tsx` is now a thin shell (295 lines) orchestrating providers and the main view switch.

## Structure Overview
The monolithic application has been split into domain-specific subdirectories inside `src/`:
- `constants/` - `springs.tsx` (animation constants)
- `components/layout/` - Shell layouts (`TopBar`, `BottomNavigation`, `Sidebar`, `GlobalCutoff`)
- `components/ui/` - Generic UI primitives (`Button`, `StatusPill`, `BottomSheet`, `Lifecycle`, `SearchField`, etc.)
- `components/home/` - Home dashboard components (`NextDeliveryHero`, `RecentActivityList`, `UpcomingDeliveryRow`)
- `components/new-order/` - New order flow (`OrderTypeSelector`, `DesktopOrderSummary`, `MobileOrderSummarySheet`)
- `components/review/` - Order review (`ReviewProductList`, `SubmissionError`, `ConfirmationCard`)
- `components/order-detail/` - Unified order detail (`OrderDetailHero`, `OrderDetailLifecycle`, `OrderActivity`)
- `components/receipt/` - Delivery receipt flow (`ReceiptReadOnlySummary`, `ReceiptGoodRows`, `ReceiptIssueRow`, `IssueChips`)
- `pages/` - Top-level route components (`HomePage`, `NewOrderPage`, `ReviewOrderPage`, `OrderConfirmationPage`, `OrderDetailPage`, `ReceiptFlowPage`, `OrdersPage`, `DeliveriesPage`)

*Note: The global state remains within `App.tsx` for now as it directly dictates the router's view switch, preventing prop-drilling into the layout shell, but the components themselves are fully decoupled.*

## Dependencies
- Used absolute/relative imports automatically generated by the extraction script to prevent circular dependencies.
- Extracted shared constants, mock data, and utility functions were imported into their respective consumer components.

## Cleanup Candidates
- **Legacy Deferred Data**: `deferredProducts` and `deferredStages` were extracted to `data/deferredData.tsx` but seem to be part of an older pattern. If the unified `OrderDetailPage` fully replaces the older deferred views, this file and its usages could be safely removed in a future feature pass.
